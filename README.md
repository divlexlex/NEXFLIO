# NEXFLIO: A Booking Management System with AI-Supported Data Analytics

## 📖 Project Overview
NEXFLIO is a centralized information system designed for Perfect Nails Wellness and Aesthetics. It aims to replace manual, non-integrated workflows with a unified platform that consolidates business operations. By transforming operational data into organized reports and visual insights, it supports managerial monitoring and evidence-based decision-making.

## 🎯 General Objective
To develop NEXFLIO: A Business Management System with AI-Supported Data Analytics for Perfect Nails Wellness and Aesthetics. The system streamlines daily operations involving appointments, customer management, inventory, and transactions while integrating AI-supported data analytics to monitor performance and identify business trends.

## 📌 Specific Objectives
1. To develop an appointment, transaction, and inventory management module that streamlines daily operations and reduces fragmented processes.
2. To develop a Customer Relationship Management (CRM) module to manage integrated customer information and appointment histories.
3. To integrate data analytics and dashboard reporting that provide visual summaries and assist management in data-driven decision-making.

## ⚙️ Core System Modules
* **Business Management System:** Centralizes Service Catalog, Appointment Scheduling, Client Management, Billing, Employee Management, and Inventory Tracking.
* **System Audit Trail:** A forensic, append-only log tracking all significant actions with a strict "no-delete" policy to guarantee data integrity and absolute accountability.
* **AI-Supported Data Analytics:** Utilizes machine learning and the Google Gemini API to identify trends, generate readable data summaries, and present key performance indicators on a management dashboard.

## 🛠 Technology Stack
* **Backend:** PHP Laravel (MVC) & Eloquent ORM
* **Frontend:** Flutter (Mobile), Bootstrap & CSS3 (Web)
* **Database:** Azure SQL Database
* **AI & Integrations:** Google Dialogflow ES, Google Gemini API, and SendGrid API
